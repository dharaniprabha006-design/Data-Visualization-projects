README - Sales and Profit Analysis
Project

Sales and Profit Analysis using Power BI

Description

This project analyzes Sales, Profit, Quantity, Products, Customers, Regions, Markets, and Shipping using Power BI visualizations.

Tools
Power BI
Power Query
Sales Dataset
Objectives
Analyze Sales and Profit by category, region, market, and customer segment.
Identify top products and cities.
Find products with negative profit.
Analyze monthly sales trends.
Study Discount vs Profit.
Analyze shipping modes and order priorities.

Visualizations
Bar Chart
Column Chart
Clustered Column Chart
Line Chart
Scatter Chart
Donut Chart
Map
Stacked Column Chart

Conclusion

The dashboard provides a clear view of business performance and helps identify sales trends, profitable areas, loss-making products, and opportunities for improvement.
